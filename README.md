# CyberShield

CyberShield is a cybersecurity monitoring system developed using Python Flask and MySQL.

The project provides realtime security monitoring, unauthorized login detection, brute-force attack detection, API-based alert monitoring, and file integrity monitoring.

## Features

- File Integrity Monitoring (FIM)
- Realtime Security Alerts
- Unauthorized Login Detection
- Brute Force Detection
- Suspicious IP Tracking
- API-Based Threat Monitoring
- Role-Based Access Control
- Dashboard Analytics
- Realtime Alert Notifications
- Report Generation

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python Flask
- Flask-SocketIO
- Flask-Mail

### Database
- MySQL
